# 扩展工具与工作区接口

新增工具前先确定：在哪台机器执行、需要哪些授权、结果发送到哪里。核心连接须能在工具未安装或不可用时独立运行。

## 接入位置

| 类型 | 模块 | 示例 |
| --- | --- | --- |
| VPS 外部服务 | `installer/prepare-mcp.py` 管理远端私有配置 | Tavily |
| 桥接维护的 Windows 工具 | `plugin/runtime/mcp-runtime.mjs` 维护进程和工具过滤 | Playwright |
| T3/ACP 提供的 MCP | `shim/http-mcp-client.mjs` 维护本机连接 | T3 内置和自定义 MCP |
| 新的工作区动作 | 更新 `workspace-request-schema.json`、远端解析和本机执行 | — |

## 提交前验证

1. **定义接口**：参数、用途、数据流和依赖。公开示例用虚构地址，密钥由使用者提供。
2. **映射权限**：区分读取、写入、启动程序和外部动作。涉及本机工作区时使用会话绑定、路径判断和写入协调。
3. **说明生命周期**：进程如何关闭、请求如何取消、超时和断线后在哪里查询。
4. **隔离测试**：验证启用、禁用、缺少依赖、权限拒绝、跨项目请求、并发和取消。
5. **诊断输出**：只含阶段、版本和脱敏错误。不用授权头或完整工具结果作为公开样本。

扩展完成后按 [贡献指南](../CONTRIBUTING.md) 运行检查。
